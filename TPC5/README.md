## Resumo
Desenvolva um programa em Python para implementar uma aplicação de gestão de alunos e turmas, através de um menu interativo que permita criar e gerir uma turma armazenada internamente. Cada aluno deverá ser representado pelo seu nome, identificador (id) e uma lista de três notas, correspondentes ao TPC, projeto e teste. O utilizador deverá poder criar uma turma, inserir alunos, listar todos os alunos, consultar um aluno pelo seu id, guardar a turma num ficheiro e carregar uma turma a partir de um ficheiro. O menu deverá ser apresentado repetidamente até que o utilizador escolha a opção de sair, momento em que a aplicação termina.
