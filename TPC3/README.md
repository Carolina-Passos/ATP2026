## Resumo
Desenvolva um programa em Python para implementar o jogo "Corrida para o 100", no qual o utilizador e o computador somam alternadamente números de 1 a 10 a um total inicial de 0. O primeiro jogador a atingir exatamente 100 vence. O programa deve permitir escolher quem começa e incluir uma versão em que o computador joga primeiro (e vence sempre usando a estratégia vencedora) e outra em que o utilizador joga primeiro, podendo o computador ganhar ou perder consoante as jogadas efetuadas.
